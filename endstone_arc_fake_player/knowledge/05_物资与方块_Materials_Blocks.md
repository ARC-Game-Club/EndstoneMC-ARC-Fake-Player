# 5. 物资与方块（Materials & Blocks）

## 5.1 矿物与矿石分布高度
见 [2.2 镐](#22-镐pickaxe采矿等级) 中的高度表。常用矿物：煤炭、铜、铁、金、红石、青金石、钻石、绿宝石、下界石英、远古残骸。

## 5.2 木材类型（含 26.50 新增白杨木）
- 橡木、云杉、白桦、丛林、金合欢、深色橡木（主世界）；
- 绯红木、诡异木（下界）；
- **白杨木（Poplar，26.50 新增）**：生成于斑驳森林（Dappled Forest），有三种叶色（红/橙/黄）树苗，可剥皮，可制白杨木板及全套木制品（见 12）。
- 每种木材均可制成：木板、楼梯、台阶、栅栏、栅栏门、告示牌、悬挂式告示牌、按钮、压力板、门、活板门、船、带箱子的船、书架（新增）。

## 5.3 独有 / 差异方块与物品
- **草径（Grass Path）**：用铲子对草方块使用生成，高 15/16，破坏掉泥土（村庄道路用此代替碎石路）。
- **稻草床（Straw Bed，26.50）**：用干草块合成，可睡过夜晚但**不改变重生点**，一次性（用后销毁）；不能在下界/末地使用（见 12）。
- **垫子（Cushion，26.50）**：用对应颜色羊毛台阶合成，可坐，16 色。
- **层架蘑菇（Shelf Mushroom，26.50）**、**红色灌木（Red Shrub，26.50）**：斑驳森林生成。
- **羊毛楼梯 / 羊毛台阶、混凝土楼梯 / 混凝土台阶（26.50）**：各 16 色。
- **教育版方块**：允许（Allow）、拒绝（Deny）、边界（Border）、NPC、元素方块、黑板（Chalkboard）等——仅特定世界/教育模式可用。
- **下界反应核（Nether Reactor Core）**等旧特性属历史内容。
- 炼药锅可染色皮革装备、可浸染箭头（见 7.5、8.2）。

## 5.4 可收集生存物资总览
- **基础资源**：木头/木板、圆石、石头、沙子、沙砾、泥土、粘土、雪、冰、玻璃。
- **矿石与锭**： Coal→煤；Iron→铁锭；Gold→金锭；Copper→铜锭；Diamond；Emerald；Lapis；Redstone；Netherite Scrap+Gold→Netherite Ingot；Quartz。
- **食物源**：小麦、胡萝卜、土豆、甜菜、南瓜、西瓜、可可豆、甘蔗、蘑菇、甜浆果、发光浆果、蜜蜂（蜜脾/蜂蜜瓶）、各类动物肉、鱼。
- **特殊**：末影珍珠、烈焰棒、恶魂之泪、龙息、下界疣、鞘翅、潮涌核心、三叉戟、重锤、不死图腾、染料（墨囊/可可/青金石/骨粉仍可作染料）。
